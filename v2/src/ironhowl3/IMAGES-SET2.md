# Ironhowl 3: images to generate, set 2 (47–86)

Set 1 was numbers 1–46 and is already in the game. This set carries on from **47**, so the file names never clash.

What it's for:
- **Session 4 (places):** the field and the docks, plus better woods ground.
- **Reference sheets:** for the mech and the enemies, so I can model them closer to a real design.
- **A few surfaces to put onto the models.**

## How to make them

- **Size:** as big as your generator allows. Square (1:1) unless the entry says **wide** (2:1). I compress and resize everything myself.
- **Reference sheets (47–52):** I never put these in the game. I look at them while I build the 3D models in Blender. A clear, plain-background design sheet matters more than a pretty picture.
- **Textures (53–58, 60–67, 71–73, 75–79, 81–84):** these must look flat. Straight-on view, even light, no shadows, no shine and no perspective. Each prompt already says this. If your generator has a "tile" or "seamless" switch, turn it on. If not, I'll make them tile.
- **Cut-outs (59, 68, 70, 74, 85):** on a pure black background, except 86, which is on white. That lets me cut them out cleanly.
- **Skies (69, 80):** wide 2:1, as big as possible.
- **Text:** signs and logos may come out a bit garbled. That's OK, so keep whichever version looks best.
- **Sending them:** same as last time. Zips or batches in this chat, named with the numbers they hold (for example "47–55"), or one Google Drive folder. If any are missing, send the rest and I'll make the missing ones in code.

Each prompt below is ready to copy and paste.
